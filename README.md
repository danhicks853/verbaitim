# VerbAItim

Post-ready bits for [@readverbaitim.bsky.social](https://bsky.app/profile/readverbaitim.bsky.social).

## Layout

- `bits/` — approved, redacted, ready-to-post artifacts (tracked)
- `raw/`  — working material, unprocessed (**gitignored, never committed**)

## Rules

- Raw material never enters git history. Process it, approve it, *then* it lands in `bits/`.
- Nothing goes to `bits/` until it's been checked for anything that shouldn't be public.
- See `CLAUDE.md` for the full working brief.

## Sync

Private repo, cloned on both machines. `git pull` before working, `git push` after.
